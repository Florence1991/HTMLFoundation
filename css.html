What is CSS?

CSS stands for "Cascading Style Sheets.” CSS is used to style the content of a web page by adding design elements like colors, fonts, and spacing. You can use CSS to change the look and feel of any element on a web page, from the overall layout to individual HTML tags.


The History of CSS Before CSS (Early 1990s)


In the early days of the web, HTML was used for both the structure and appearance of web pages. Developers used HTML tags such as font, center, and color attributes to style content. This approach made web pages difficult to maintain because the styling was mixed with the content.

The Birth of CSS (1994)

In 1994, Håkon Wium Lie, a Norwegian computer scientist, proposed the idea of Cascading Style Sheets (CSS) while working at CERN. His goal was to separate the presentation (how a page looks) from the content (what a page says). Later, Bert Bos joined him, and together they developed the CSS specification.


The World Wide Web Consortium (W3C) officially released CSS Level 1 (CSS1) in 1996.

CSS1 introduced basic styling features such as:

  • Fonts
  • Text colors
  • Background colors
  • Margins
  • Padding
  • Borders

This was the first standard that allowed developers to style web pages consistently.

Modern CSS

Today, CSS continues to evolve through new modules rather than major version numbers. Modern CSS includes powerful features such as:

  • Flexbox for one-dimensional layouts
  • CSS Grid for two-dimensional layouts
  • Custom Properties (CSS Variables)
  • Container Queries
  • Subgrid
  • Improved animations and color features

These additions make it possible to build complex, responsive layouts with much less code than in the past.
